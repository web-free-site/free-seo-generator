How to add JSON-LD schema to a page

JSON-LD is a way to describe a page in a script tag so machines can read a structured summary (what the page is, its title, a FAQ, a business name). It is not a ranking guarantee. Free SEO Generator can build a JSON-LD block you paste into the page.

Steps

  1. Choose a type that matches the page. Use Article for an article, FAQPage only if the FAQ is visible on the page, and a business type only if you are describing a real business you represent.
  2. Fill the fields accurately. Open the JSON-LD generator and enter names, URLs, and text that already appear on the page. Do not invent reviews, ratings, or availability.
  3. Copy the script tag. Generate the JSON-LD and copy the script block of type application/ld+json.
  4. Paste it into the page and test. Place it in the HTML (often in the head or at the end of the body). Then preview the page and, when you can, test the markup in a structured-data testing tool of your choice.

Keep markup in sync with visible content

Structured data should describe what a user can already see. Misleading markup can be ignored or cause problems in search products.

One purpose per block

It is better to have a small, correct JSON-LD block than a large file with empty or guessed properties.
